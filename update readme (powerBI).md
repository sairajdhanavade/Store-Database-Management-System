# 🛒 Store Database Management System & Interactive Dashboard

A comprehensive end-to-end data project that manages store inventory, sales, and customer data using a robust **SQL backend** and provides actionable business insights via an interactive **Power BI Dashboard**.

## 🌟 Project Overview
This project solves the problem of tracking store performance and inventory in real-time. By integrating a structured relational database with modern visualization tools, it allows stakeholders to:
- Monitor daily sales and revenue trends.
- Manage inventory levels to prevent stockouts.
- Analyze customer demographics and purchasing behavior.

## 🛠 Tech Stack
- **Database:** MySQL / SQL Server (SQL scripts included for DDL & DML)
- **Visualization:** Power BI Desktop
- **Data Processing:** Power Query (ETL) & DAX (Measures)
- **Documentation:** Markdown

## 🗄 Database Schema
The backend consists of a normalized relational schema including:
- `Products`: Details of all items in stock.
- `Customers`: Information on registered shoppers.
- `Orders`: Transaction records linking customers and products.
- `Categories`: Classification for inventory management.

**Key Visualizations:**
- **Sales Overview:** Monthly and yearly revenue growth.
- **Inventory Status:** Real-time stock counts by category.
- **Top Products:** Identification of best-selling items using DAX.
- **Geographic Analysis:** Customer distribution map.



## 📈 Key Insights
- **Top Category:** Electronics contributed to 40% of total revenue.
- **Low Stock Alert:** 5 items are currently below the safety threshold.
- **Peak Performance:** Sales peak typically occurs during the first week of the month.
